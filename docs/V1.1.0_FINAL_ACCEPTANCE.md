### Runtime hardening

- Neural embedding cold-start timeout is configurable (`EMBEDDING_TIMEOUT_SECONDS`, default runtime `120s`).
- Qdrant request timeout is configurable (`QDRANT_TIMEOUT_SECONDS`, default runtime `10s`).
- Indexing failures identify the failing stage (`embedding` or `qdrant`).
- Diagnostics exclude document text, API keys, and vector values.
- Runtime status endpoint reports quality mode, provider configuration, timeout settings, and application version.

## Release artifacts required before publishing the tag

The release script `scripts/release-v1.1.0.ps1` must freshly produce:

- `KnowFlow-AI-v1.1.0-Android.apk`
- `KnowFlow-AI-v1.1.0-HarmonyOS-x64.hap`
- `KnowFlow-AI-v1.1.0-HarmonyOS-arm64.hap`
- `SHA256SUMS.txt`
- `release-metadata.json`

The script refuses to tag if:

- current branch is not `main`
- local `main` differs from `origin/main`
- the working tree is dirty
- signing/secrets are tracked by Git
- tests fail
- any APK/HAP build fails
- the tag already exists
- GitHub CLI is not authenticated

## External / out-of-scope conditions

These are not v1.1.0 engineering PASS requirements:

- Android physical-device certification
- HarmonyOS physical-device certification
- ARM64 physical runtime acceptance
- Google Play production signing
- AppGallery production signing
- paid neural embedding provider

## Release decision

Code and quality acceptance: `PASS`.

Tag/GitHub Release publication is permitted only after the fresh local release script completes all three platform builds and SHA256 generation. The frozen v1.0.0 tag must never be moved.
