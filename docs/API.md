# API

Base prefix: `/api/v1`. OpenAPI is available at `/docs` when the server runs.

Implemented routes include `/health`, `/ready`, `/auth/demo`, `/auth/register`, `/users/me`, knowledge-base/document CRUD, `/chat`, `/chat/stream`, conversations, learning plans/tasks, quizzes/submit, mastery, knowledge graph, stats, repositories/import, and agents/tools. Bearer JWT is required for user resources; ownership is checked server-side.
