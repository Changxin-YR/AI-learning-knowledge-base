# KnowFlow AI v1.1.0

KnowFlow AI v1.1.0 upgrades the RAG pipeline from deterministic/vector infrastructure validation to a measured neural retrieval and evidence-verification pipeline.

## RAG quality pipeline

- Multilingual MiniLM neural embedding (`384` dimensions)
- Qdrant vector retrieval with ownership filters
- Lexical + Vector Reciprocal Rank Fusion
- Multilingual MMARCO Cross-Encoder reranking
- DeepSeek/OpenAI-compatible strict evidence-sufficiency verification
- Fail-closed `verified` mode when the evidence verifier is unavailable

Runtime modes:

- `RAG_QUALITY_MODE=basic`
- `RAG_QUALITY_MODE=rerank`
- `RAG_QUALITY_MODE=verified`

## Runtime hardening

- Embedding timeout is configurable with `EMBEDDING_TIMEOUT_SECONDS` (default runtime value: 120s).
- Qdrant timeout is configurable with `QDRANT_TIMEOUT_SECONDS` (default runtime value: 10s).
- Indexing failures emit stage-level diagnostics (`embedding` / `qdrant`) without logging document text, API keys, or vector contents.
- `/api/v1/runtime-quality` exposes active quality mode and timeout settings.
