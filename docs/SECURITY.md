# Security

Passwords use Argon2id. JWTs expire, production refuses the built-in development secret, and all protected resources verify user ownership. Uploads reject path traversal, unsupported extensions, invalid documents and files over 10 MiB. Repository imports allow only GitHub, GitLab, and Gitee hosts, resolve DNS before cloning, reject private/loopback/link-local/multicast/reserved addresses, use shallow non-recursive clones, cap file and repository sizes, and never execute repository code. Agent tools dispatch through services rather than SQL and write audit rows without secrets. Markdown is rendered as plain text in the mobile client, avoiding executable HTML.
