# RAG

Uploads are validated by safe basename, extension and size. PDF, DOCX, PPTX, Markdown and source text are converted to text before splitting at headings/paragraph boundaries, then stored with document and section metadata. Retrieval uses deterministic hybrid lexical features (word, Chinese character, bigram and trigram overlap) and omits zero-overlap citations. Chat responses include the selected chunk id, filename, section and preview as citations. There is no Qdrant/Embedding dependency in the local path yet; this is intentionally a lexical fallback, not vector search or model reranking. `/chat/stream` currently emits deterministic tool, message and done SSE events; it is not token streaming.
