# RAG

Uploads are validated by safe basename, extension and size. PDF, DOCX, PPTX, Markdown and source text are converted to text before splitting at headings/paragraph boundaries, then stored with document and section metadata. SQLite owns relational metadata; Qdrant stores vectors with `user_id`, `knowledge_base_id`, `document_id` and `chunk_id` payloads. `RAG_MODE=lexical|vector|hybrid` selects retrieval; the default hybrid path uses reciprocal-rank fusion and a vector similarity threshold, while zero-overlap/under-threshold results produce zero citations. `EMBEDDING_PROVIDER=local` is a lightweight deterministic offline vectorizer for repeatable tests; `openai` uses the OpenAI-compatible `EMBEDDING_BASE_URL`, `EMBEDDING_API_KEY` and `EMBEDDING_MODEL` variables. The local provider is not a neural semantic model, so production semantic quality requires configuring the OpenAI-compatible provider or adding a cached local model implementation. Upload, repository indexing, document deletion and KB deletion update Qdrant when it is available and retain lexical fallback when it is not. `/chat/stream` currently emits deterministic tool, message and done SSE events; it is not token streaming.
